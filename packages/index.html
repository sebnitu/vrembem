Packages

Vrembem is organized as a collection of packages. These can be included a la carte or using the all inclusively vrembem barrel package.

Core

Manage library wide config, tokens, and base styles.

Button

A simple component that allows users to trigger an action.

Card

A flexible and highly composable content container.

Checkbox

Allow users to select multiple options from a set.

Content

Provides typographic styles for commonly used HTML elements.

Drawer

A content container that switches contexts based on a provided breakpoint.

Flex

A simple flexbox based layout component.

Grid

A simple grid based layout component.

Input

A component for displaying form input elements.

Menu

Groups of links, actions or tools that a user can interact with.

Modal

Dialogs that block interaction with other elements on the page.

Notice

A component for highlighting messages to the user.

Panel

A structured content container with optional header, and footer sections.

Popover

An initially hidden component that is revealed upon user interaction.

Radio

Allow users to select a single option from a set.

Select

Allow users to select an option from a dropdown menu.

Switch

Allow users to toggle between a binary option.

Table

Provides style variants for displaying tabular data.

Utility

Atomic classes that specialize in setting single style properties.
